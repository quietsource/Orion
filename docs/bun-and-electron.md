# Bun and Tauri

This converted edition uses Bun for dependency installation, TypeScript checking, bundling and backend execution. Its standalone compiled service includes Bun; end users install neither Node.js nor Bun. Tauri v2 uses the operating system webview and Rust for native desktop integration.

Run bun install, bun run dev, or bun run dist from this child directory. The original Electron source in the parent is unaffected.
