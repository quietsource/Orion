Set up Orion Create
Orion can install and manage a private headless ComfyUI runtime for local image and video generation. This downloads Python packages and takes additional disk space. It runs only when you use Create.


Set up Orion model browser
The in-app model browser uses a private, managed copy of llama.cpp to run downloaded GGUF models locally. Orion will detect the best available CPU or GPU runtime and install only the required files on this device.
This is optional. You can keep using Ollama models without installing it, or install it later from the model browser.
