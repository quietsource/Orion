Local cron schedules run while Orion is running. Enable the system tray setting to keep them running after closing the window. Times use your device timezone. You can also ask Orion to create a schedule; Orion can create schedules when recurring follow-up would clearly help.

Set up Orion Create
Orion can download and manage its compact, Vulkan-accelerated stable-diffusion.cpp runtime for local Stable Diffusion image and Wan video generation. The runtime is downloaded on demand and runs only when you use Create.


Set up Orion model engines
The in-app model browser runs downloaded models through private, managed local engines. Orion installs only the files this device needs.
llama.cpp runs downloaded GGUF models on the CPU or GPU, with automatic runtime detection for NVIDIA, AMD, Vulkan and Apple hardware.
Orion inference is bundled with Orion and runs downloaded GGUF models locally using the new CUDA-enabled runtime. You can also select llama.cpp or Ollama for a chat whenever those engines are available.
This is optional. You can keep using Ollama models without installing an engine, or install one later from the model browser.
